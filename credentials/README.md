Централизованное хранение учётных данных

Цель: предоставить единый, безопасный способ хранить и получать доступ к секретам (GitHub, Timeweb, Yandex, Bitrix и т.д.) из любого проекта на этой машине.

Рекомендации:
- Секреты хранятся в зашифрованном файле в домашней директории пользователя (`~/.timeweb_credentials.enc`).
- Используйте мастер-пароль при инициализации; мастер-пароль не хранится.
- Не добавляйте зашифрованный файл в репозиторий; храните только шаблоны/пример в репо.

Файлы в этой папке:
- `credentials.example.yaml` — шаблон структуры для ручного заполнения.
- `credman.py` — утилита для инициализации/добавления/получения секретов.

Пример использования:
```bash
# инициализация (создаст salt и пустой зашифрованный store)
python credentials/credman.py init

# добавить учётные данные для сервиса
python credentials/credman.py add github --key token

# получить все данные сервиса
python credentials/credman.py get github
```

Безопасность:
- Выберите надёжный мастер-пароль и храните его в менеджере паролей.
- При необходимости интегрируйте этот store с системным ключницом (Windows Credential Manager, Keychain, Secret Service).
